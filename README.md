# CLIP-vs-human-cosine-similarity-game
# How much do YOU align to an AI / CLIP?
Instructions:
- Put path/to/your/images in a1 and a4
- Run the files in order
- For a2, you'll have to rank images by *your* Theory-of-Mind-for-CLIP cosine similarity (default: 100 pairs)!

![ToM-for-CLIP](https://github.com/user-attachments/assets/2512e3ec-4626-43c1-b56a-96ee43b80781)

- Very arbitrarily inspired by the paper [On convex decision regions in deep network representations](https://www.nature.com/articles/s41467-025-60809-y)
- "[...] understanding machine learned latent spaces and their relations to human representations [...] in cognitive science, convexity is found to
support generalization, few-shot learning, and interpersonal alignment [...] offers new insights into learning mechanisms, human-machine alignment"
- Pondering: 🤔 Wait, if they align future AI to human, but I am aligned to AI by then - will future AI be misaligned to ME?
- Question: How much do I see like a CLIP sees? (Human-AI-alignment) -> This code 🙃
